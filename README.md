# Data Analytics for Smart Agriculture Using Weather and Soil Sensor Data

## Project Description
This project analyzes weather and soil sensor data to support smart agricultural decision-making. It uses data analytics to monitor soil moisture, temperature, humidity, and rainfall.

## Objectives
- Monitor soil and weather conditions.
- Analyze agricultural sensor data.
- Identify irrigation requirements.
- Support data-driven farming decisions.
- Reduce water and resource wastage.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Streamlit
- CSV Dataset

## Features
- Upload and display agricultural data.
- Analyze soil moisture.
- Visualize temperature data.
- Monitor weather conditions.
- Provide irrigation recommendations.

## Installation

Install the required libraries:

pip install -r requirements.txt

## Run the Project

Run the following command:

streamlit run app.py

## Project Files

- `app.py` – Main application
- `agriculture_data.csv` – Sensor dataset
- `requirements.txt` – Required Python libraries
- `README.md` – Project documentation

## Expected Output
The application displays sensor data, graphs, and an irrigation recommendation based on soil moisture.

## Conclusion
The project demonstrates how data analytics can be used with weather and soil sensor data to improve agricultural decisions and promote smart and sustainable farming.
